# Tumor-Detection-from-MRI-image
MATLAB implementation for detecting and segmenting brain tumor regions from MRI images, developed as part of a graduate research project. A GUI was also made where an image can be uploaded, and the code can automatically process that image and give the output images in a graphical user interface.
# Brain Tumor Detection from MRI Images

This repository contains MATLAB code developed to detect and segment tumor regions in brain MRI images as part of a graduate research project.

## Requirements
- MATLAB
- Required MATLAB toolboxes (if applicable)

## Methodology
The implementation applies image processing techniques to identify and segment suspected tumor regions from brain MRI images.

## How to Run
1. Download the repository.
2. Open MATLAB.
3. Open the main MATLAB script.
4. Provide an input MRI image as required by the script.
5. Run the code to visualize the detection and segmentation results.

## Output
The code produces image-processing results showing the detected tumor region.

## Academic Purpose
This project was developed for academic research and demonstration purposes. It is not intended for clinical diagnosis.
